pytest-resources releases (verified 2026-09-27, v0.3.2): version is dynamic from git tags (uv-dynamic-versioning); flow = fix commit + "chore(release): X.Y.Z" commit touching only CHANGELOG (Unreleased -> dated section) + `git tag vX.Y.Z` + `git push origin vX.Y.Z` (IMPORTANT: `push --follow-tags` SKIPS lightweight tags — push the tag explicitly). Release workflow publishes PyPI + GitHub Release in ~40s, no approval gates. Consumers: same-day releases need exclude-newer-package exemptions in the consuming project (e-arkhetypo exempts e-serde and pytest-resources). 0.3.2 widened `[serde]` extra to e-serde>=0.2,<0.6 after a resolution conflict; templates must register eserde_loaders() in conftest (plugin default is stdlib-only since 0.3.0).
