# e-api

Generic **e-stack** API service template: Litestar + Granian + msgspec on uv, Rust-backed tooling end to end.
The common modules (`infra/`, `ops/`, `ports/`, `providers/`, `engines/`, `processors/`) live once in `../common` and are materialized here by `make common`.

##### LAYOUT #####

```
src/e_api/       # the service: api/ (lifespan, routers, security), models/, websockets/
src/infra/       # GENERATED by `make common` from projects/python/common — edit there, never here
src/ops/         # GENERATED by `make common` from projects/python/common — edit there, never here
src/ports/       # GENERATED by `make common` from projects/python/common — edit there, never here
src/providers/   # GENERATED by `make common` from projects/python/common — edit there, never here
src/engines/     # GENERATED by `make common` from projects/python/common — edit there, never here
src/processors/  # GENERATED by `make common` from projects/python/common — edit there, never here
tests/unit/      # mirrors src, import-mode=importlib; no service in the default run
tests/support/   # the fakes the mirror shares (a scripted psqlpy pool) — redis rides fakeredis
Dockerfile       # two-stage: builder (uv) + deploy (python-slim, non-root)
compose.yml      # single e-api service, :8000
```

##### TAXONOMY #####

Providers sit by capability — `providers/<drivers|adapters>/<capability>/<name>.py` (`providers.drivers.store.redis`,
`providers.drivers.http.wreq`, `providers.drivers.database.psqlpy`) — and the settings mirror that tree:
`st.providers.drivers.store.redis.url`, `st.app.port`. Every exception descends from `infra.errors.CoreError`; the
service's own live in `e_api` and stay out of that tree. Env variable names are unchanged (`REDIS_URL`, `POSTGRES_DSN`).

##### USAGE #####

```bash
make install        # materialize infra + sync deps
make run            # python -m e_api
make check          # lint + type + arch + validate + infra-drift + test
make integration    # the tests marked `integration` (a real service); out of check, test and cov
make stress         # soak concurrent-load tests
make up             # docker compose up
```

`make` alone lists every target.
