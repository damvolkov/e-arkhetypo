# e-cli

Generic **e-stack** command-line template: cyclopts on uv, msgspec end to end, Rust-backed tooling.
The common modules (`infra/`, `ops/`, `adapters/`) live once in `../infra` and are materialized here by `make infra`.

##### LAYOUT #####

```
src/e_cli/cli.py        # composition root: GROUPS + CARDS tables → the cyclopts tree; `ecli` script
src/e_cli/commands/     # one file per noun, one plain async function per verb — never imported until run
src/e_cli/runtime/      # launcher (global options, error boundary) · lifespan (one run) · deps (injection) · journal (undo)
src/e_cli/models/       # command tree schema, identity, session, journal entry, typed errors, demo domain
src/infra/              # GENERATED by `make infra` from projects/python/infra — edit there, never here
src/ops/                # GENERATED by `make infra` from projects/python/infra — edit there, never here
src/adapters/           # GENERATED by `make infra` from projects/python/infra — edit there, never here
tests/unit/             # mirrors src, import-mode=importlib
```

##### A RUN #####

```
ecli [--token T] [--verbose] GROUP ... COMMAND ARGS
 └─ Launcher.run        global options; parse_args resolves (and only now imports) the command
     └─ lifespan        logs → stderr, infra singletons loaded, `shared` + `session` sealed into the State graph
         └─ Deps        builds only what the command declares: Inject[StorePort] · Inject[Identity] · Inject[Console] · …
             └─ command plain async function; raises CliError subclasses, never prints failures or exits
 ← exit code            0 · CliError.exit_code (IdentityError 3 · JournalError 4 · ProjectError 5)
```

##### ADDING A COMMAND #####

1. Write a plain function in `commands/<noun>.py`. Parsed arguments are ordinary parameters; everything
   the runtime supplies is `Inject[T]` — keyword-only, hidden from `--help`, resolved by type:

   ```python
   async def rename(old: str, new: str, *, store: Inject[StorePort], me: Inject[Identity], console: Inject[Console]) -> None:
       """Rename a project.

       Args:
           old: current name.
           new: new name.
       """
   ```

2. Add one row to `CARDS` in `cli.py`: `CommandCard(path="project rename", target="e_cli.commands.project:rename", summary="…")`.
   A new group is one row in `GROUPS`, parents before children.

Asking for `Identity` is how a command requires a login. Writing through the injected `StorePort` is how it
becomes undoable: the store is wrapped in `StoreJournal`, which records the prior value of every key and
files the run on a clean exit — `ecli history undo` restores it. A new injectable is one builder and one
row in `Deps.PROVIDERS`.

##### USAGE #####

```bash
make install                         # materialize infra + sync deps + git hooks
make run project create demo         # uv run ecli project create demo
make check                           # lint + type + arch + validate + drift + test
uv run ecli --help                   # served from the cards: no command module is imported
```

Auth resolves per run: `--token` → `CLI_TOKEN` → the login stored by `ecli auth login`. `make` alone lists every target.
