# cfi

The CFI code (ISO 10962) classifies a financial instrument with six capital letters: position 1 is the
category (D = debt instrument), position 2 the group within it (B bond, C convertible bond, W bond with
warrants, T medium-term note, Y money market, G mortgage-backed, Q asset-backed, N municipal, D
depositary receipt, M other), positions 3–6 attributes (interest type, underlying asset — S equities, I
index, B basket — optionality, form). A letter X means the attribute is unspecified or unknown — in any position except the
category, the group included when the debt type matches no named letter (usage table dated 2026-10-14). An equity-index-linked note under a shelf programme is a debt instrument:
the code opens with D.
