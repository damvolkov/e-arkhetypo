compose

e_infra.ops.compose

ops/compose: discover a stack tree and merge chosen fragments into one parameterized document.

StackCompose reads <root>/<category>/<service>/compose.yml and answers two things: a flat catalog of what is available (discover, optionally with the host-reference edges each service names) and the merged document (merge), built from the chosen names or from in-memory fragment mappings — the objects the stack machinery answers for a chosen service. Everything travels on plain e-serde mappings: anchors and << merge keys are resolved at load, so the engine only ever sees data. The merge follows compose-go rules — unique lists append and dedup, environment and networks unify as maps, mappings merge recursively, scalars take the last word — and then applies the policy: the declarable one held in SpecCompose (project name, port pattern, network name, volume root) and the two imposable laws of the house stack, never configurable: every service carries container_name and hostname equal to its name, and every relative or named volume binds under data/<service>/. Interpolated published ports (${WEB_PORT:-8080}) pass through untouched — they are already parameterized; validation of the result belongs to docker compose config at deploy time.

ServiceCompose

SpecCompose

Bases: Struct

The declarable policy: project name, port pattern ({name} {port} {host}), shared network name, volume root.

A pattern whose result contains a colon sets the ip (short form) or host_ip (long form); the entry's own binding is kept otherwise. Interpolated entries pass through untouched.

StackCompose 

StackCompose(
    root: Path | None = None,
    *,
    spec: SpecCompose | None = None,
    **fields: Any,
)

The tool: discover the tree, merge the choice, configure the policy, render the result.

Dispatch is structural: the compose class of each key — unique list, environment map, network map, nested mapping, plain scalar — decides the rule through match, never through branching chains. Nothing given is mutated: every fragment is copied into the merged model.
