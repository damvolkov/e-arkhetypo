# downside-threshold

The level of the underlying below which the investor starts losing principal at maturity. When the Final
Value is at or above the Downside Threshold (and the note was never called), the stated principal is
repaid; below it, the payout falls proportionally to the decline of the underlying, up to a total loss.
It is usually a percentage (e.g. 75%) of the Initial Value; a note whose coupon barrier equals its
downside threshold is "fully at risk" below that level.
